================================================================================
                    IPL AUCTION ARENA - STARTUP GUIDE
================================================================================

--------------------------------------------------------------------------------
1. PASTE YOUR GEMINI API KEY IN .env
--------------------------------------------------------------------------------
Open the file named ".env" in either the root folder or inside the "backend" folder:
    D:\IPl_Auction\.env
    D:\IPl_Auction\backend\.env

Replace "YOUR_GEMINI_API_KEY_HERE" with your actual key from Google AI Studio:
    GEMINI_API_KEY=AIzaSy...YourActualKeyHere...

(If you don't have a key yet, get a free key from: https://aistudio.google.com/app/apikey)
*Note: The app will run smoothly even without a key using authentic built-in fallback commentary!*


--------------------------------------------------------------------------------
2. START THE BACKEND (TERMINAL 1)
--------------------------------------------------------------------------------
Open PowerShell or Command Prompt (CMD) in the project directory (D:\IPl_Auction):

Step 1: Go into the backend directory:
    cd D:\IPl_Auction\backend

Step 2: Create Python Virtual Environment (only needed once):
    python -m venv venv

Step 3: Activate the Virtual Environment:
    - On Windows PowerShell:
        .\venv\Scripts\Activate.ps1
      (If PowerShell says script execution is disabled, run: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass, then activate again)
    - On Windows Command Prompt (CMD):
        .\venv\Scripts\activate.bat
    - On Mac/Linux:
        source venv/bin/activate

Step 4: Install Python dependencies:
    pip install -r requirements.txt

Step 5: Start the FastAPI Backend Server:
    uvicorn main:app --host 0.0.0.0 --port 8000 --reload

The backend is now live at:
    API URL:  http://localhost:8000
    API Docs: http://localhost:8000/docs


--------------------------------------------------------------------------------
3. START THE FRONTEND (TERMINAL 2)
--------------------------------------------------------------------------------
Open a SECOND terminal window in the project directory (D:\IPl_Auction):

Step 1: Go into the frontend directory:
    cd D:\IPl_Auction\frontend

Step 2: Install Node dependencies (only needed once):
    npm install

Step 3: Start the Next.js frontend development server:
    npm run dev

The frontend is now running at:
    App URL: http://localhost:3000


--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
1. Open your web browser and navigate to:
    http://localhost:3000
